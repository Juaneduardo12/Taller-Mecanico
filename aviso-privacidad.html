2. ¿Qué datos personales recabamos?

3. ¿Para qué usamos tus datos?

Usamos tus datos para las siguientes finalidades, necesarias para darte el servicio:

4. ¿Dónde se almacenan y con quién se comparten?

Tus datos se almacenan con un proveedor de infraestructura tecnológica en la nube (Supabase), cuyos servidores se encuentran en Estados Unidos. Este proveedor los trata únicamente por cuenta del Taller y para prestarle ese servicio. Para la verificación contra robots usamos Cloudflare Turnstile, que recibe datos técnicos de tu navegador (como tu dirección IP) únicamente para ese fin. No vendemos tus datos ni los compartimos con terceros para sus propios fines, salvo que una autoridad competente lo requiera conforme a la ley.

Para ejercer cualquiera de estos derechos, envía tu solicitud a [CORREO ELECTRÓNICO DE CONTACTO PARA PRIVACIDAD] o preséntala en [DOMICILIO O TELÉFONO], indicando tu nombre completo, el correo con el que te registraste, qué derecho quieres ejercer y una descripción clara de tu solicitud. Aplicamos medidas administrativas, técnicas y físicas razonables para proteger tus datos: el acceso a la información se controla por rol (cada persona solo ve lo que necesita), las contraseñas se almacenan cifradas y la conexión con el sitio es segura.

Este sitio usa únicamente almacenamiento técnico necesario para funcionar:

  • La verificación de seguridad contra robots (Cloudflare Turnstile), que puede guardar información técnica en tu navegador para distinguir a una persona de un programa automático.

Puedes borrar estos datos desde la configuración de tu navegador; si lo haces, tendrás que iniciar sesión de nuevo.
